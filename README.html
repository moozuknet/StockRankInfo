📊 README - 증시 시가총액 변동 분석 & 텔레그램 자동 발송 웹 UI

v3.3.2 Release Google Apps Script

Google Apps Script(GAS)와 Modern TailwindCSS Web UI 기반으로 개발된 한국 증시(NXT 프리마켓 / KRX·NXT 정규장 / 통합 애프터마켓) 및 미국 증시(US 본장) 시가총액 변동 자동 분석 및 텔레그램 리포팅 시스템입니다.

📸 대시보드 & 시황 멀티 차트 / 히트맵 스크린샷

1) 투자자별 매매동향 종합 멀티라인 차트 (v3.3.2 최신)

💡 영웅문 [0251] 스타일 다중축(Dual-Axis) 4선 복합 차트: 좌측축(지수 pt)과 우측축(누적 금액 억 원) 위에 KOSPI/KOSDAQ 지수(파랑), 개인(주황), 외국인(빨강), 기관계(청록) 4개 곡선을 장중 시간대별(09:00~15:30 전 구간 200개 시계열)로 완벽히 재현하여 지수 흐름과 수급 주체의 방향성을 100% 동일하게 한눈에 파악합니다.

코스피(KOSPI) 투자자별 종합 차트 코스닥(KOSDAQ) 투자자별 종합 차트

2) 웹 설정 대시보드 (Web App UI)

💡 v3.3.2 최신 대시보드 화면: KOSPI/KOSDAQ 독립 수신, 4대 시장 세션 스케줄러, WICS 섹터 및 최고점 대비 등락률(고점 대비 +,-%) 표기 옵션이 반영된 반응형 UI입니다.

3) 코스피 / 코스닥 주요 섹터별 전 종목 히트맵 (1200x1200 HD)

💡 한경 마켓맵 / 핀비즈 스타일 계층형 트리맵: 섹터별 클러스터링과 크고 굵은 종목명 폰트(최대 38pt BOLD)가 적용된 초고해상도 히트맵입니다.

🌟 핵심 기능 요약

  1. 📈 최상단 지수 종합 시황 및 영웅문 스타일 수급 멀티 차트 연동 (v3.3.2)
    • 지수 요약 및 당일 수급 브리핑: 👤개인 +29,972억 | 🏢외국인 -20,704억 | 🏛기관계 -16,789억 실시간 순매수/순매도 누적 금액 최상단 표기.
    • 영웅문 [0251] 스타일 다중축 4선 복합 차트: 지수(좌측축)와 3대 수급 주체(우측축) 동시 렌더링.
    • 장중 1분봉 및 시간대별 수급 100% 동일 동기화: 네이버 시계열 API(startIdx 0~3, 총 200개 아이템) 연동으로 09:00~15:30 전 구간 수급 곡선 일치.
    • 텔레그램 전송 안정성 최적화: QuickChart 단축 URL 쿼리 파라미터 충돌(HTTP 400) 방지 및 네이버 차트 자동 폴백 탑재.
  2. 🗺️ 한경 마켓맵 / 핀비즈 스타일 계층형 히트맵 엔진 (v3.2+)
    • 업종별 섹터 클러스터링: 전기·전자, 2차전지·화학, 제약·바이오 등 섹터별 주도주 타일링.
    • 크고 굵은 종목명 폰트 분리: 대형주 최대 38pt BOLD, 일반 종목 최소 16pt 이상 가독성 확보.
    • 국내 증시 표준 7단계 정밀 컬러 그라데이션 및 1200x1200 HD 정사각 타일링.
  3. 📱 3단계 스마트 순차 전송 파이프라인 (v3.0+)
    • 1단계: 헤더 & 최상단 지수 종합 시황 및 당일 수급 브리핑 발송
    • 2단계: 영웅문 스타일 4선 멀티 차트 + 고품질 전 종목 히트맵 묶음 사진 앨범(sendMediaGroup) 발송
    • 3단계: 종목별 시가총액 순위 분석 & 핵심 요약 리포트 본문 발송
  4. 📱 Web UI 설정 대시보드 (`Index.html`)
    • 코스피 & 코스닥 분리 수신 제어 및 WICS 표준 79개 섹터 정보 매핑.
    • 텔레그램 다중 Bot 연동 및 2026.09.14 개편 시장별 4대 시간대별(프리마켓/정규장/애프터마켓/미국장) 발송 스케줄러.
    • 휴장일 자동 제외, 최고점 대비 등락률(showHighDiff), 순위 급등/급락 분석 옵션.
