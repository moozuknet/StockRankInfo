📊 README - 증시 시가총액 변동 분석 & 텔레그램 자동 발송 웹 UI

v2.5.0 Release Google Apps Script

Google Apps Script(GAS)와 Modern TailwindCSS Web UI 기반으로 개발된 한국 증시(NXT 프리마켓 / KRX·NXT 정규장 / 통합 애프터마켓) 및 미국 증시(US 본장) 시가총액 변동 자동 분석 및 텔레그램 리포팅 시스템입니다.

🌟 핵심 기능 요약

  1. 📱 Web UI 설정 대시보드 (`Index.html`)
    • 코스피(KOSPI) & 코스닥(KOSDAK) 분리 수신 설정 (v2.4+): 국내 시장 분석 시 코스피와 코스닥을 구분하여 독립적인 상위 종목 및 섹터 리포트 수신 가능.
    • 종목별 WICS 표준 섹터(업종) 정보 제공 (v2.4+): 79개 WICS 표준 업종 코드 체계(NAVER_INDUSTRY_MAP) 연동 및 대형주 팩트 섹터 캐시 탑재.
    • 텔레그램 다중 Bot 연동 관리 (v2.1+): 여러 개의 텔레그램 봇 등록 및 활성/비활성 제어.
    • 2026.09.14 개편 시장별 4대 시간대별 발송 제어 (v2.3+):
      • 🌅 국내 프리마켓 마감 (평일 08:55 KST): NXT 장전 프리마켓(08:00~08:50) 마감 및 개장 준비 브리핑.
      • 📊 국내 정규장 마감 (평일 15:35 KST): KRX & NXT 정규 메인마켓(09:00~15:30) 종가 확정 후 코스피/코스닥 마감 시총 분석.
      • 🌙 국내 통합 애프터마켓 마감 (평일 20:05 KST): KRX(16:00~20:00) & NXT(15:40~20:00) 실시간 접속매매 최종 마감 분석.
      • 🇺🇸 미국 본장 마감 (화~토 05:05/06:05 KST): NYSE & NASDAQ 본장 마감 및 서머타임 연동 분석.
    • 실시간 리포트 미리보기 시장 전환 탭: KOSPI / KOSDAK / US 실시간 데이터 수집 및 텔레그램 모달 팝업 미리보기.
    • 최고점 대비 등락률(%) 표기 서식 (v2.5+): 각 종목별 최고가(52주 최고가) 대비 현재가 등락률(+,-%) 및 최고가 금액을 상세 리포트에 동적 표기(showHighDiff).
    • 실시간 장운영 상태 안내 위젯: 4대 시장의 실시간 개장/대기/마감 상태 대시보드 표시.
  2. ⚙️ 백엔드 데이터 처리 & 자동화 (`Code.gs`)
    • 코스피 / 코스닥 독립 Top N 파이프라인: 시장별 독립 상위 종목 수집 및 순차 발송.
    • 2계층 하이브리드 섹터 조회 엔진: 대형주 팩트 캐시(Layer 1, 0ms) + 실시간 네이버 모바일 통합 API 조회(Layer 2).
    • 2026.09.14 KRX/NXT 최신 운영시간 반영: 시간외단일가 폐지 및 애프터마켓 실시간 접속매매 전환에 맞춘 정밀 스케줄링.
    • 휴장일 판별 하이브리드 엔진: 대한민국 공휴일, 근로자의 날, 연말 결산 휴장일 및 미국 증시 공휴일 자동 건너뛰기.
    • 미국 서머타임(DST) 자동 처리: EDT(05:05 KST) / EST(06:05 KST) 자동 전환.
