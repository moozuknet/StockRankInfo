# 📊 증시 시가총액 변동 분석 & 텔레그램 자동 발송 웹 UI (GAS Project)

> **Google Apps Script(GAS)**와 **Modern TailwindCSS Web UI** 기반으로 개발된 한국 증시(NXT 프리마켓 / KRX·NXT 정규장 / 통합 애프터마켓) 및 미국 증시(US 본장) 시가총액 변동 자동 분석 및 텔레그램 리포팅 시스템입니다.

## 🌟 핵심 기능 요약

1. **📈 최상단 지수 종합 시황 및 공식 차트 연동 (v3.0+)**
   - **시장별 핵심 지수 요약 노출**:
     - 🇰🇷 **국내 증시(KOSPI / KOSDAK)**: 코스피 지수 및 코스닥 지수의 현재 지수, 전일 대비 변동값(`+,-`), 등락률(`%`)을 리포트 최상단에 우선 표시.
     - 🇺🇸 **미국 증시(US)**: 글로벌 대표 핵심 지수인 **나스닥 종합(IXIC)** 및 **S&P 500(SPX)** 지수를 최상단에 브리핑 (불필요한 다우존스 제외).
   - **네이버 공식 지수 차트 실시간 연동**:
     - 코스피, 코스닥, 나스닥, S&P 500의 네이버 금융 공식 일봉/당일 지수 차트 이미지를 연동.
     - 텔레그램 서버의 이미지 캐싱으로 인한 구 데이터 노출을 원천 방지하기 위해 실시간 타임스탬프(`?t=Date.now()`) 자동 부착.

2. **🗺️ 한경 마켓맵 / 핀비즈 스타일 계층형 히트맵(트리맵) 엔진 (v3.2+)**
   - **업종별 섹터 클러스터링 (Grouping)**:
     - 단순 업종명만 나열되는 것이 아닌, **`■ 전기·전자`, `■ 2차전지·화학`, `■ 제약·바이오`, `■ 자동차·운송`, `■ 금융·지주`, `■ 기계·방산`, `■ IT·서비스`** 등 주요 섹터 헤더 아래 **시장 대표 주도주들이 시가총액 크기 비례 사각형으로 빈틈없이 타일링**.
   - **크고 굵은 종목명 폰트(`<b>` BOLD 분리 적용)**:
     - 모바일 텔레그램에서 탭하여 확대했을 때도 종목명이 흐리거나 작지 않도록 **대형주 최대 38pt BOLD**, **중형주 24~30pt BOLD**, **일반 종목 최소 16pt 이상 BOLD**로 전면 강화.
     - 등락률 폰트와 크기를 계층화하여 종목명이 한눈에 들어오는 가독성 확보.
   - **국내 증시 표준 7단계 정밀 컬러 그라데이션**:
     - `+3% 이상(밝은 빨강)`, `+1.5%~+3%(빨강)`, `+0.5%~+1.5%(연빨강)`, `0%(보합 다크 슬레이트)`, `-1.5%~-0.5%(약보합 그레이)`, `-2.5%~-1.5%(파랑)`, `-4% 이하(딥블루)`.
     - (미국 증시는 상승 녹색 / 하락 빨강 자동 전환)
   - **초고해상도 1200x1200 HD 정사각 캔버스**:
     - 모바일 텔레그램 화면에 최적화된 1:1 정사각 뷰로 레터박스(빈 여백) 없이 화면에 꽉 차게 렌더링.

3. **📱 3단계 스마트 순차 전송 파이프라인 (v3.0+)**
   - 수신자의 열람 흐름에 최적화된 **3단계 순차 텔레그램 전송**:
     1. **1단계**: `[헤더 & 최상단 지수 종합 시황]` 텍스트 발송
     2. **2단계**: `[네이버 공식 지수 차트 + 고품질 전 종목 히트맵]` 묶음 사진 앨범(`sendMediaGroup`) 발송 (시황 바로 아래 위치)
     3. **3단계**: `[종목별 시가총액 순위 분석 & 핵심 요약 리포트]` 본문 텍스트 순차 발송
   - 메시지 내 링크 미리보기 배너로 인한 스크롤 낭비를 방지하기 위해 `disable_web_page_preview: true` 기본 적용.

4. **📱 Web UI 설정 대시보드 (`Index.html`)**
   - **코스피(KOSPI) & 코스닥(KOSDAK) 분리 수신 설정**: 국내 증시 분석 시 코스피와 코스닥을 구분하여 독립적인 상위 종목 리포트 수신 가능 (`enableKospi`, `enableKosdak`).
   - **종목별 WICS 표준 섹터(업종) 정보 제공**: 79개 WICS 표준 업종 코드 체계 연동 및 대형주 팩트 섹터 캐시 탑재 (`#1 종목명 (시장 · 섹터)`).
   - **텔레그램 다중 Bot 연동 관리**: 여러 개의 텔레그램 봇(별칭, Bot Token, Chat ID) 등록 및 활성/비활성 제어, 개별/전체 즉각적인 연동 테스트 지원.
   - **2026.09.14 개편 시장별 4대 시간대별 발송 제어**:
     - 🌅 **국내 프리마켓 마감 (평일 08:55 KST)**: NXT 장전 프리마켓(08:00~08:50) 마감 및 개장 준비 브리핑.
     - 📊 **국내 정규장 마감 (평일 15:35 KST)**: KRX & NXT 정규 메인마켓(09:00~15:30) 종가 확정 후 마감 시총 분석.
     - 🌙 **국내 통합 애프터마켓 마감 (평일 20:05 KST)**: KRX(16:00~20:00) & NXT(15:40~20:00) 실시간 접속매매 최종 마감 분석.
     - 🇺🇸 **미국 본장 마감 (화~토 05:05/06:05 KST)**: NYSE & NASDAQ 본장 마감 및 서머타임 연동 분석.
   - **알림 수신 항목 커스터마이징**:
     - **휴장일 자동 발송 제외**: 주말(토/일), 법정 공휴일, 근로자의 날(5/1), 연말 휴장일(12/31) 및 미국 증시 공휴일 시 중복 시황 발송 자동 건너뛰기 (`skipHolidays`).
     - 조회 범위: 시가총액 상위 10위 / 20위 / 30위 / 50위 선택.
     - 과거 비교 시점: **1일 전 / 5일 전 / 1개월 전 / 3개월 전 / 1년 전** 다중 선택.
     - **최고점 대비 등락률 표기 (`showHighDiff`)**: 종목별 최고가(52주 최고가) 대비 현재가 변동률(+,-%) 및 최고가 금액 노출.
     - **순위 변동 기준 급등/급락 분석**: 순위 변동폭 기준 순위 급등(▲계단) 및 급락(▼계단) 요약.

## 📩 텔레그램 수신 메시지 흐름 예시

### [1단계 메시지: 헤더 & 지수 종합 시황]
```html
<b>[📊 국내 정규장 - 코스피(KOSPI) 마감 시총 분석]</b>
🗓 <b>기준 일시:</b> 2026-10-08 15:35:00 (KST)
📊 <b>조회 범위:</b> 상위 20개 종목
📌 <b>순위 변동:</b> ▲ 상승 | ▼ 하락 | ➖ 유지
📌 <b>강조 아이콘:</b> 🚀 10계단+ 급등 | 🔥 5계단+ 상승 | 🚨 10계단+ 급락
───────────────────
📈 <b>[종합 시황 지수]</b>
• <b>코스피:</b> 2,580.40 (🔺 +12.30, +0.48%)
• <b>코스닥:</b> 745.20 (🔺 +3.10, +0.42%)
───────────────────
```
