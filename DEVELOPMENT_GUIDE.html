🛠 DEVELOPMENT GUIDE - 증시 시가총액 변동 분석 & 텔레그램 자동 발송

본 문서는 Google Apps Script(GAS) 프로젝트 생성부터 텔레그램 봇 연동, Clasp CLI 자동화 배포, 2026년 9월 14일 개편된 KRX/NXT(대체거래소) 최신 운영시간 기준의 시간대별 Market Data Engine 파이프라인 구조, 및 보안 유지보수에 대한 종합 개발 가이드입니다.

1. 📝 Google Apps Script 프로젝트 구성 및 Clasp CLI 자동화

# 1. 의존성 및 clasp 설치 확인
npx clasp --version

# 2. 로컬 코드 온라인 GAS 프로젝트로 강제 푸시 (.claspignore 자동 적용)
npx clasp push --force

# 3. 새로운 버전 생성 및 배포 (Production Web App)
npx clasp deploy --description "v2.0 Release - KRX/NXT Time-based Multi-session Engine"

# 4. 활성화된 배포 목록 및 실행 ID 확인
npx clasp deployments

2. ⏰ 2026.09.14 KRX & NXT 시장 운영시간 전면 개편 명세

2026년 9월 14일부터 한국 주식시장에 대체거래소(NXT, 넥스트레이드)와의 복수 거래소 경쟁 체제가 본격 가동되며 마켓별 운영 시간 및 거래 제도가 획기적으로 개편되었습니다.

구분 넥스트레이드 (NXT 대체거래소) 한국거래소 (KRX) 비고 및 주요 특징
프리마켓 (Pre-market) 08:00 ~ 08:50 미운영 (2027년 말 도입 예정) 장 시작 전 실시간 접속매매 (출근길 거래 선점)
메인마켓 (정규장) 09:00:30 ~ 15:20 09:00 ~ 15:30 정규 거래 세션 (KRX와 NXT 동시 운영)
장후 시간외종가 - 15:40 ~ 16:00 당일 정규장 종가 고정 가격 매매
애프터마켓 (After-market) 15:40 ~ 20:00 16:00 ~ 20:00 기존 10분 단위 시간외단일가 폐지 → 실시간 접속매매 전면 도입

2026.09.14 개편 주요 제도 변경사항

  • 체결 방식 혁신: 기존의 10분 단위 단일가 호출매매가 폐지되고, 정규장과 동일하게 호가가 일치하면 즉시 체결되는 실시간 접속매매(Continuous Trading) 방식으로 변경되었습니다.
  • 가격 제한폭 대폭 확대: 기존 시간외단일가(당일 종가 대비 ±10%)에서 정규장과 동일한 전일 종가 대비 ±30%로 확대되었습니다.
  • 주문 효력 및 스마트 주문(SOR): NXT는 프리마켓→메인마켓→애프터마켓까지 단일 세션으로 주문 효력이 유지되며, 증권사 SOR(최선집행서비스)을 통해 두 거래소 중 유리한 곳으로 자동 분기됩니다.
  • 거래 대상 및 제외 종목: 변동성 관리를 위해 ETF(상장지수펀드) 및 ETN(상장지수증권)은 현재 양대 거래소 모두 애프터마켓 거래 대상에서 제외됩니다.

3. 📊 시간대별 Market Data Engine 및 KOSPI / KOSDAK · 섹터 파이프라인 (`Code.gs`)

국내 증시 분석 시 코스피(KOSPI)와 코스닥(KOSDAK)을 명확히 분리하여 각각 분석하며, 종목별 WICS 표준 섹터(업종) 정보를 결합하여 수급과 모멘텀을 정밀 분석합니다.

1) 코스피 & 코스닥 분리 수집 및 독립 설정

  • 수신 설정 필드: enableKospi(기본값 true), enableKosdak(기본값 true). 원하는 시장만 단독 선택하거나 양대 시장 모두 수신 가능.
  • 독립 Top N 산출: KOSPI 상위 N개, KOSDAK 상위 N개를 각각 독립 산출하여 코스닥 핵심 주도주(바이오, 2차전지, 로봇 등) 누락 방지.
  • 독립 메시지 발송: 각 시장별 리포트를 순차 발송하여 텔레그램 4,096자 제한 방지 및 가독성 확보.

2) 종목별 섹터(업종) 정보 파이프라인

  • WICS 79개 표준 업종: 네이버 증권 WICS 코드 체계(NAVER_INDUSTRY_MAP) 연동.
  • 2계층 하이브리드 엔진: 대형주 팩트 섹터 캐시(Layer 1, 0ms) + 실시간 industryCode 동적 조회(Layer 2).
  • 리포트 표기 서식: #1 종목명 (시장 · 섹터) (설정 showSector 지원).
발송 시각 (KST) 핸들러 함수 세션 타이틀 핵심 분석 내용

화~토 05:05/06:05 sendUsReport [🇺🇸 미국 증시 마감 시총 분석] 미국 본장(16:00 EDT/EST) 마감 후 엔비디아/빅테크 중심 글로벌 시총 변동 및 테크 섹터 분석

3) 최고점 대비 현재가 등락률(%) 산출 파이프라인 (config.showHighDiff)

  • 옵션 명칭: showHighDiff (기본값 true, 리포트 상세 서식 옵션 내 체크박스).
  • 수집 엔진: 네이버 모바일 통합 API의 52주 최고가(highPriceOf52Weeks)를 UrlFetchApp.fetchAll 병렬 배치 호출로 1~2초 내 초고속 수집. 미국 종목은 Yahoo Finance fiftyTwoWeekHigh 활용.
  • Fallback 캐시: KRX_HISTORICAL_MAP에 주요 대형주 고점 데이터(highPrice) 사전 적재로 API 장애 시에도 안전한 무중단 서식 보장.
  • 계산 공식: 등락률(%) = ((현재가 - 최고점) / 최고점) * 100 (고점 대비 하락폭 음수 표기, 신고가 도달 시 0.00% / 양수 표기).
  • 리포트 출력 서식: └ 고점 대비: -27.37% (최고 380,000원) 라인을 종목별 정보에 동적 노출.
